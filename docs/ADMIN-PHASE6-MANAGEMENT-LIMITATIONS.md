# Business Management authority and limits

Business Management is read-only. The dashboard owns immediate work, BI owns period analysis, and the original destinations retain mutations. Existing authenticated Admin roles can see operational references and account-link events. Onboarding decisions and financial activity, commission policy, and recovery diagnostics require owner or admin. The existing dashboard surge editor retains all four authorised roles.

Source fare rules and membership terms are references. Effective membership and fee policy is observed through the existing database policy RPC. Missing, incompatible and failed policy evidence is shown separately. Resolved release and outbox switches do not establish schema installation, live health, uptime or successful delivery.

Recorded activity uses separate 25-row pages, timestamp and ID ordering, and exact-count reconciliation. This is not a complete audit trail. Account linking is replay-keyed. Payment proof and membership rows show their latest recorded reviewed state. Surge updater metadata describes the last save only. Missing links or actors remain unknown. Paging across mutable records does not provide a database snapshot.

Maps usage distinguishes the serving process from shared recorded telemetry over the preceding 24 hours. Recovery is limited to the 100 most recent recorded jobs. No full backlog, provider health or automated repair is inferred.

Deferred work includes transactional FIN-04, authoritative operating areas, dispatch candidate database coverage, regional administration, durable cross-domain audit history, company-profile editing, Admin role administration, runtime fare and commission editing, editable service catalogues, runtime feature rollout, historical integration health, authoritative full recovery backlog reporting and the advanced BI items in the Phase 5 limitations. No new administrative mutation is introduced.

Authenticated runtime, rendered accessibility and browser acceptance, production schema availability, historical completeness and query performance remain unverified. Existing browser tooling limitations still apply.
